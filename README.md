# github-colorizer
Colorize background of pull requests depending on target branch

## 📩 Obtain

Clone this repo

## 🎨 Customize

Change colors for branch prefixes in `content.js` to suit your needs.

## 🚀 Load

1. Go to `chrome://extensions/` or `edge://extensions/`
1. Enable Developer mode
1. Click _Load unpacked_
1. Select the cloned folder

## 💻 Use

Now, whenever you open a GitHub PR page, the background will change based on the target branch name.
